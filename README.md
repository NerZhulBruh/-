## Краткое резюме продукта

**«Рядом»** — сервис ручного подбора кружков и секций для детей 4–12 лет.  
Целевая аудитория: занятые родители 28–42 лет в городах 500+ тыс. человек.

**Главные боли (из 24 интервью):**
- Дорога после работы (15/24)
- Стоимость становится известна слишком поздно (9/24)

**Первая версия:** лендинг + ручной подбор 2–3 вариантов с проверкой логистики и полной стоимости.  
Нет: приложения, полного каталога, автоматического поиска, ЛК, оплаты.

**Гипотеза первого экрана:**  
Если сразу показать, что подбор учитывает время в пути после работы и полную стоимость → вырастет доля заявок.

## Как использовать пакет
Команда может сразу брать:
- текст первого экрана → в вёрстку лендинга
- JTBD и гипотезы → в бэклог проверки
- список задач → в план на ближайшие 1–2 недели
- таблицу альтернатив → для аргументации отличий сервиса

Дальнейшие устные пояснения не требуются.
