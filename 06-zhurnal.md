# Этап 6. Библиотека промптов и журнал правок

## Библиотека промптов (5–7 ключевых)

### 1. План исследования (этап 1, zero-shot)
```
Ты — продуктовый исследователь. На основе следующих данных подготовь план исследования сервиса «Рядом» из ровно пяти шагов.

Данные:
- Сервис помогает родителям 28–42 лет в городах 500+ тыс. выбирать кружки/секции для детей 4–12 лет.
- Главные проблемы из 24 интервью: дорога после работы (15/24), сравнение в 4+ источниках (11/24), стоимость только по телефону (9/24).
- Первая версия: только лендинг + ручной подбор. Нет приложения, полного каталога, автоматического поиска, ЛК, оплаты.
- Команда: основатель + дизайнер.

Задача: предложить план из 5 последовательных шагов исследования, который позволит подготовить продуктовый пакет (анализ аудитории и альтернатив, описание первой версии, гипотезы, материалы для лендинга).

Формат ответа:
Для каждого шага укажи:
1. Какой вопрос решает шаг.
2. Что именно спросить у нейросети (конкретная формулировка задачи).
3. Какой результат будет достаточным для перехода к следующему шагу.
4. Какие утверждения нельзя использовать без проверки источника.

Не добавляй примеры планов и не делай выводы о рынке.
```

### 2. Сравнение альтернатив (этап 2) — первоначальный
```
Сравни четыре способа, которыми родители ищут кружки и секции для детей 4–12 лет:
1. Навигатор дополнительного образования
2. Один частный каталог или доска услуг
3. Карты или афиша
4. Родительский чат

Для каждой альтернативы выясни:
- можно ли узнать стоимость занятий до обращения;
- доступна ли информация о расположении и дороге;
- указаны ли возраст детей и расписание занятий;
- что может сделать родитель, если вариант ему не подошёл.

Представь результаты в виде таблицы. Отдельно опиши аудиторию на основе 24 интервью: кто принимает решение, на каком этапе прекращают поиск, какие способы пробовали, какой информации не хватает.
```

### 3. Сравнение альтернатив — уточнённый
```
Сравни четыре альтернативы поиска кружков/секций для детей 4–12 лет:
1. Навигатор дополнительного образования (региональные порталы)
2. Частный каталог (возьми реальный пример, например inRing)
3. Карты (Яндекс/2ГИС) или афиша
4. Родительский чат

Критерии для каждой:
- Видна ли полная стоимость до обращения (включая возможные взносы)
- Есть ли данные о расположении + возможность оценить дорогу/время после работы
- Указаны ли возраст и актуальное расписание
- Что делать, если вариант не подошёл

Представь строго в таблице. 
Отдельно: описание аудитории только на основе 24 интервью (не обобщай на всех родителей).
Раздели сведения на: Факт / Гипотеза / Неподтверждённое.
Не добавляй сервисы, которые ты не можешь подтвердить ссылкой.
```

### 4. Классификация жалобы (этап 3, few-shot)
```
Отнеси фразу к одной из категорий:
- Дорога и расписание
- Стоимость становится известна слишком поздно
- Неясно, насколько безопасно место и кто проводит занятия
- Положительный отзыв о конкретном кружке
- Другое

Примеры:
«После работы ехать через весь город — час в пробке» → Дорога и расписание
«На сайте красиво, а по телефону цена другая и группа набрана» → Стоимость становится известна слишком поздно
«В чате хвалят, но никто не пишет адрес и сколько стоит» → Другое

Фраза: «Нам всё нравилось, пока не сказали, что форма и взносы отдельно, и это ещё плюс четыре тысячи».
```

### 5. JTBD + гипотеза первого экрана (этап 3)
```
Преобразуй три высказывания в формулировки «Когда я…, я хочу…, чтобы…». 
Не добавляй функции, которых нет в первой версии (нет каталога, нет оплаты, нет ЛК).

Фразы:
1. «Нам всё нравилось, пока не сказали, что форма и взносы отдельно, и это ещё плюс четыре тысячи».
2. «Каждую осень заново обзваниваю одни и те же залы».
3. «В чате хвалят секцию, а где она находится — никто не пишет».

Затем сформулируй одну гипотезу первого экрана по шаблону «Если…, то…, потому что…». 
Метрика — доля посетителей, оставивших заявку. 
Гипотеза должна предполагать одно изменение первого экрана.
```

### 6. Текст первого экрана (этап 4) — первоначальный
```
На основе трёх JTBD и проблемы, которую не решают альтернативы, напиши текст первого экрана лендинга «Рядом».

Требования:
- Заголовок ≤ 10 слов
- Подзаголовок ≤ 20 слов
- Кнопка ≤ 4 слов (ведёт к заявке, не к регистрации)
- Понятно, для кого подходит и для кого нет
- Не обещать полный каталог, подбор за минуту, безопасность

Подготовь 2 варианта и выбери один с обоснованием.
```

### 7. Текст первого экрана — уточнённый (использованы результаты этапа 3)
```
Используй БЕЗ ИЗМЕНЕНИЙ эти три формулировки:
1. Когда я выбираю кружок и мне уже почти всё нравится, я хочу заранее знать полную стоимость вместе с формой и взносами, чтобы не сталкиваться с неприятным сюрпризом...
2. Когда я каждую осень начинаю поиск заново, я хочу иметь под рукой актуальные варианты с адресом, расписанием и ценой...
3. Когда я читаю в чате восторженные отзывы о секции, я хочу сразу понимать, где она находится и сколько займёт дорога после работы...

И одну проблему, которую не решают альтернативы: ни один способ одновременно не показывает полную стоимость + реальное время в пути после работы + актуальные места.

Напиши 2 варианта первого экрана лендинга.
Ограничения первой версии: только ручной подбор, нет каталога, нет оплаты, нет ЛК.
Заголовок ≤10 слов, подзаголовок ≤20, кнопка ≤4.
Не обещай то, чего команда из двух человек не может гарантировать.
```

```
В начале списка должны быть задачи, без которых нельзя показать первый экран и принимать заявки.
Не добавляй регистрацию, оплату, полноценный каталог.
```
